# 無茶振り！師範ラン

元写真7枚、Blender製の人物スプライト、画像生成した「師範ワールド」を組み合わせた、ブラウザで遊べる横スクロール2Dアクションです。

写真街、コード沼、ガラクタ工場、バランス海岸、師範城を走り抜けます。道中では短い「無茶振り」が突然発生。制限時間内に、いつもの操作だけで命令を達成してください。

## 操作

操作は方向キーとAボタンだけです。スマホでは画面下の十字キーと大きなAボタンを使います。

- `←` `→`: 移動
- `↑`: ジャンプ
- `↓`: 空中で踏みつけ
- `A`: 攻撃
- キーボードのAボタン: `Z` / `Space` / `Enter`
- `P`: 一時停止

## ゲーム内容

- 走る、ジャンプ、攻撃、踏みつけの2Dアクション
- ペン、瓶、ケーブルなど写真街ならではの敵
- 5地区と巨大ボス戦
- 数秒だけ割り込む高速な「無茶振り」
- 写真カード収集、コンボ、スコア、ランク
- PC・スマートフォンの両方に対応

## 起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。ビルド工程や外部ライブラリは不要です。

## 素材

- 元写真: `assets/pose-1.jpg` 〜 `assets/pose-7.jpg`
- Blender編集データ: `models/pose-dojo.blend`
- Blender自動生成スクリプト: `blender/build_assets.py`
- 人物スプライト: `assets/renders/`
- 画像生成した背景: `assets/generated-*.png`

人物の立ち姿、構え、背面、ダッシュの各ポーズはBlender 5.2でモデリング・レンダリングしています。
