# 無茶振り！ポーズ道場

元写真7枚、Blender製3Dモデル、画像生成した「師範ワールド」を組み合わせた高速マイクロゲーム集です。4〜6秒ごとに命令と操作が変わり、元写真を看板やモニターへ加工した写真街、コード沼、ガラクタ工場、バランス海岸、師範城を巡りながら、4回失敗するまでスコアを競います。

## 13種類の無茶振り

- 写真を指定ポーズで止める
- スワイプで振り向かせる
- 左右交互に腕を動かす
- 3D師範の重心を保つ
- 飛来するペンを避ける
- 落ちる瓶を受ける
- ケーブルを振りほどく
- 7枚から背面写真を探す
- コードをジャンプする
- 長押しで力をためる
- 何も操作せず静止する
- 3D師範を丸へ運ぶ
- 10本ごとの連打ボス「師範戦」

5本ごとに速度が上がります。タップ、スワイプ、ドラッグ、長押しとキーボード操作に対応しています。

## 起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。ビルド工程や外部ライブラリは不要です。

## 素材

- 元写真: `assets/pose-1.jpg` 〜 `assets/pose-7.jpg`
- Blender編集データ: `models/pose-dojo.blend`
- Blender自動生成スクリプト: `blender/build_assets.py`
- 3Dレンダー: `assets/renders/`
- 画像生成アート: `assets/generated-*-v2.png`

人物、衣装、4ポーズ、ネオン舞台、小物、ライティングはBlender 5.2でモデリング・レンダリングしています。
