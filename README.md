# 師範ワールド 2D

ブラウザで遊べる全画面ドット絵の横スクロール2Dアクションです。元写真は人物の外見を作るための参照にだけ使い、ゲーム内には表示しません。プレイヤーは灰色の髪・黒Tシャツ・黒い短パンを特徴にした透過ドット絵キャラクターです。

キャラクターだけでなく、空、街、足場、敵、宝石、ボス、攻撃エフェクト、タイトル、HUD、操作ボタン、結果画面まで同じ8〜16bit風に統一しています。ゲーム画面は低解像度で描画してから拡大するため、すべての輪郭がピクセル単位で表示されます。

歯車街、スライム下水道、灼熱工場、嵐の港、師範城を進み、各地区のボスを倒します。足場、穴、敵、宝石、地区の長さは、遊ぶたびに自動生成されます。

## 操作

- `←` `→`: 移動
- 画面タップ / `↑`: ジャンプ
- `↓`: 空中踏みつけ
- Aボタン / `Z` / `Space` / `Enter`: パンチ
- `P`: 一時停止

スマートフォンでは、画面下の十字キーと大きなAボタンで遊べます。命令イベントや自動走行はなく、自分で動かす純粋な2Dアクションです。

## ゲーム内容

- 待機・歩行2種・ジャンプ・構え・パンチ・踏みつけ・ダメージの8モーション
- ペン兵、ボトル兵、ケーブルスライム
- 5地区と巨大ボス戦
- シード付き自動生成ワールド
- 宝石8個ごとのライフ回復
- 入力猶予付きジャンプとスマホ向けの広い攻撃判定
- スコア、宝石数、撃破数、到達ランク

## 起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。ビルド工程や外部ライブラリは不要です。

## 汎用ワールド生成

- `worlds.js`: 地区テーマと自動生成器
- `game.js`: 生成結果を遊べる形にするゲームエンジン

`worlds.js` の `DEFAULT_PRESET.areas` に地区を追加すると、ゲーム側を変えずに新しい地区を生成できます。名前、色、空の色、背景形状、長さ、足場、敵、宝石、穴、難易度、ボスを地区ごとに設定できます。

同じ世界はシード付きURLで再現できます。

```text
http://localhost:8000/?seed=123456789
```

## ドット絵素材

- ゲーム用透過スプライト: `assets/pixel-hero-sheet-v1.png`
- 透過処理前の生成結果: `assets/pixel-hero-sheet-chroma-v1.png`

ゲーム用シートは4列×2行です。上段が待機、歩行1、歩行2、ジャンプ。下段が構え、パンチ、踏みつけ、ダメージです。
