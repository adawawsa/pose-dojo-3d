# 無茶振り！師範ラン

元写真7枚、Blender製の人物スプライト、画像生成した「師範ワールド」を組み合わせた、ブラウザで遊べる横スクロール2Dアクションです。

写真街、コード沼、ガラクタ工場、バランス海岸、師範城を走り抜けます。足場、穴、敵、写真、地区の長さは走るたびに自動生成されます。道中では短い「無茶振り」が突然発生。制限時間内に、いつもの操作だけで命令を達成してください。

## 操作

右へ自動で走るアシスト付きです。スマホではステージ画面をタップするだけでジャンプでき、画面下の十字キーと大きなAボタンでも操作できます。

- 自動走行: 右へゆっくり進む
- 画面タップ / `↑`: ジャンプ
- `←` `→`: 位置調整・ダッシュ
- `↓`: 空中で踏みつけ
- `A`: 攻撃
- キーボードのAボタン: `Z` / `Space` / `Enter`
- `P`: 一時停止

## ゲーム内容

- 走る、ジャンプ、攻撃、踏みつけの2Dアクション
- ペン、瓶、ケーブルなど写真街ならではの敵
- 5地区と巨大ボス戦
- シード付きの自動生成ワールド
- 5ライフ、写真5枚ごとのライフ回復
- 入力猶予付きジャンプと広い攻撃判定
- 数秒だけ割り込む高速な「無茶振り」
- 写真カード収集、コンボ、スコア、ランク
- PC・スマートフォンの両方に対応

## 起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。ビルド工程や外部ライブラリは不要です。

## 汎用ワールド生成

ワールド定義とゲーム本体は分離されています。

- `worlds.js`: 地区テーマと自動生成器
- `game.js`: 生成結果を遊べる形にするゲームエンジン

`worlds.js` の `DEFAULT_PRESET.areas` に地区を追加すると、ゲーム側を変更せずに新しい地区を生成できます。地区ごとに次の項目を設定できます。

- 名前、色、背景、背景形状、ミッション
- 地区の長さ
- 足場・敵・写真・穴の個数範囲
- 出現する敵の種類
- 穴の幅と難易度
- ボスと最終ボス

同じ世界はシード付きURLで再現できます。

```text
http://localhost:8000/?seed=123456789
```

結果共有時にもワールドシードが付くため、ほかのプレイヤーへ同じ配置の挑戦を渡せます。
